# AIB Android App

<p align="center">
  <img src=".github/logo.png" alt="aib-android-app logo" width="128" />
</p>

An unofficial Android app for viewing Allied Irish Banks (AIB) internet
banking accounts.

## What it does

- Logs in to AIB internet banking in two steps, asking for the last four
  digits of your home or work phone number as the site does.
- Shows accounts, a payment log and active standing orders.
- Logs you out automatically after a countdown.

## Tech

- Java for Android

## Building

This is an Eclipse Android project (`AndroidManifest.xml`,
`default.properties` and `proguard.cfg`). Import it into Eclipse with
the Android Developer Tools, or build it with the Android SDK.
